SMART PDF SCANNER ULTIMATE – PROTOTYPE PACKAGE

Included features in this browser prototype:
- Camera capture and gallery image import
- Multi-page image-to-PDF
- Rotate pages, grayscale and black-and-white filters
- PDF merge, split into one-page files, rotate all pages
- ID photo crop/resize presets and background fill (not AI background removal)
- Add text to every PDF page
- Finger-drawn signature PNG
- Image-to-text OCR (English/Hindi/Gujarati; internet needed for engine/language data)
- QR camera scanner (HTTPS and camera permission required)
- Session Trash with restore and empty trash

IMPORTANT LIMITATIONS:
This is a mobile-friendly web prototype, not a finished native Android/Play Store app.
PDF Editor here adds text to pages; it is not a full visual annotation editor.
ID Photo does not remove complex backgrounds or guarantee official photo compliance.
Trash only holds items deleted from the current page list during this session; it cannot browse/delete phone storage.
Some libraries load from CDNs, so internet is needed for PDF/OCR/QR tools.
No cloud upload, user accounts, ads, subscriptions, or server storage are included.
Before Play Store release, add privacy policy, test on devices, validate accessibility/security,
use compliant Android packaging/signing and meet current Play Console requirements.
